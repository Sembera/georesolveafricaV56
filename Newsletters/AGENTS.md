# Newsletter instructions

Read README.md in this folder before creating or revising a GeoUnlocked edition.

- The primary deliverable is the web edition. Create a PDF only when the user requests one.
- Match the published August 2026 web edition, not the August PDF or an early local draft. Inspect https://georesolveafrica.com/geounlocked-august-2026.html when using it as a live reference.
- Use the current September web edition as the implementation starting point. Reuse shared GeoUnlocked CSS, website navigation and footer; use separate edition-specific assets, CSS and JavaScript.
- Use the user's confirmed projects and source material. Do not invent survey dates, quantities, findings, clients or approvals.
- Base conceptual cover terrain on photographs of the actual site. Preserve headline space and distinguish illustrations from documentary photographs and measured results.
- Preserve original photographs and previous editions. Keep documentary image proportions and do not fabricate detail.
- Make routine reversible edits without repeated confirmation. Ask only for material missing inputs, conflicting information or publication scope.
- Build and inspect the web page at desktop and mobile widths, verify assets and controls, and record sources and cover provenance.
- Deliver a local preview by default. Deploy when the user authorizes publication; follow existing project deployment instructions.
